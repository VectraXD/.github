# VectraXD™

**3D visualization for every team, from a quick file check to a custom spatial app.**

VectraXD is a cross-platform, cross-device 3D visualization platform by Prolincur Technologies.

## Products

**01 · Preview: free 3D & BIM viewer**
View IFC, OBJ, STL, glTF/GLB, PLY, FBX, DXF, DAE, 3D Tiles, point clouds and more,
online or on desktop (Windows, macOS, Linux). No install, no sign-up.
Files are read locally and never uploaded.

**02 · Studio: no-code 3D** *(private beta)*
Build 3D scenes and product configurators, render photorealistic images, and
publish embeddable, shareable 3D. Works with Shopify, WordPress and more.

**03 · Spatial API & SDK: for developers** *(private beta)*
Recognition, vectorization, translation and reality-capture APIs, plus a
spatial SDK for building your own 3D apps.
